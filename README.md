# 1Candbox — онлайн-компилятор 1С (OneScript в браузере)

Код на языке 1С выполняется прямо в браузере: движок OneScript скомпилирован в WebAssembly и работает в фоновом потоке (Web Worker). Сервер для запуска кода не нужен, сайт — набор статических файлов.

## Сборка

```bash
./build.sh
python3 -m http.server 8080 --directory site
```

Откройте http://localhost:8080.

Перед публикацией укажите адрес сайта: из него строятся `canonical`, `og:url` и `sitemap.xml`.

```bash
SITE_URL=https://example.github.io/bsl-sandbox ./build.sh
```

Требования: .NET SDK 8+, Node.js 18+, git, python3.

## Публикация на своём сервере (Ubuntu + Caddy)

Сайт статический: собирается на своём компьютере, на сервер копируется только папка `site/`. .NET и Node на сервере не нужны.

1. Арендуйте VPS (хватит 1 vCPU и 1 ГБ RAM) с Ubuntu 22.04 или 24.04 и добавьте свой SSH-ключ для root. В DNS домена создайте A-записи для `домен` и `www.домен` на IP сервера.
2. Один раз настройте сервер: Caddy с автоматическим HTTPS, пользователь `deploy`, файрвол, вход только по ключу, автообновления.

   ```bash
   scp deploy/server-setup.sh deploy/Caddyfile root@СЕРВЕР:/root/
   ```

   ```bash
   ssh root@СЕРВЕР 'bash /root/server-setup.sh 1candbox.ru'
   ```

3. Скопируйте `deploy/deploy.env.example` в `deploy/deploy.env` (он не попадает в git), впишите `DEPLOY_HOST` и `SITE_URL`.
4. Выкладка (сборка с адресом сайта, новый релиз, переключение одной операцией):

   ```bash
   ./deploy/deploy.sh
   ```

   Откат на предыдущий релиз: `./deploy/deploy.sh --rollback`. Выложить уже собранную `site/`: `--no-build`.

Как это устроено:

- `deploy/Caddyfile` — отдаёт готовые `.br`/`.gz` из `_framework` (25 МБ → 7,6 МБ), `Cache-Control: no-cache` (браузер перепроверяет файлы и получает 304), своя страница 404, `www` → без `www`. `X-Frame-Options` не ставится: виджет встраивают на чужие сайты.
- `deploy/deploy.sh` — релизы в `/var/www/1candbox/releases/<дата-время>`, сайт отдаётся из симлинка `current`, хранятся последние 5. Неизменённые файлы rsync не передаёт заново, а связывает жёсткими ссылками с прошлым релизом, сохраняя дату: ETag не меняется, и у посетителей остаётся кэш `_framework`. Скрипт отказывается выкладывать сборку без `SITE_URL` или с другим адресом.

После первой выкладки: подтвердите сайт в Яндекс Вебмастере и Google Search Console, добавьте `https://домен/sitemap.xml`, в Вебмастере укажите регион и главное зеркало (без `www`).

## Иконки и картинка для превью

`page/public/favicon.svg` — исходник иконки, `page/assets/og-image.html` — исходник картинки для превью ссылок (`og:image`, 1200×630). Растровые файлы (`favicon.ico`, `favicon-120.png`, `apple-touch-icon.png`, `og-image.png`) лежат в `page/public/` и коммитятся. После правки исходников пересоберите их (нужен Google Chrome):

```bash
./scripts/render_images.sh
```

`og:image` попадает на страницы только при сборке с `SITE_URL`: мессенджеры принимают лишь абсолютный адрес картинки.

## Устройство

- `browser/Runner.cs` — хост OneScript: принимает код и строки ввода, возвращает вывод `Сообщить()` и ошибки (с номером строки) в JSON. Экспортирован в JavaScript через `[JSExport]`.
- `browser/bsp/*.bsl` — заглушки популярных функций БСП на языке 1С (`ОбщегоНазначенияКлиентСервер`, `ОбщегоНазначения`, `СтроковыеФункцииКлиентСервер`). Подключаются, только если код к ним обращается.
- `page/src/app.js` — главная страница: редактор, примеры, подсказки о совместимости, кнопка «Поделиться».
- `page/src/embed-app.js` и `page/public/embed.html` — виджет для `<iframe>`. Движок загружается при первом наведении или запуске.
- `page/src/embed.js` — веб-компонент `<bsl-sandbox>` для статей и блогов.
- `page/src/share.js` — код и ввод в адресе: `#c=…&i=…` (deflate + base64url), пример по ссылке: `#ex=<id>`.
- `page/build-pages.mjs` — страницы примеров `examples/<id>.html` для поисковиков, страница `404.html`, иконки и `og:image` в `<head>`, `sitemap.xml`, `robots.txt`.
- `page/public/worker.js` — загружает .NET-рантайм и вызывает `Runner.Run(code, input)`.
- `scripts/patch_onescript.py` — правки OneScript для браузера и для совместимости с платформой (формат чисел, `ОписаниеОшибки()`, предел глубины вызовов).

## Встраивание в статью

Кнопка «Поделиться» выдаёт ссылку и готовый код для вставки. Веб-компонент:

```html
<script src="https://<адрес 1Candbox>/embed.js" defer></script>
<bsl-sandbox>
<script type="text/bsl">
Сообщить("Привет, мир!");
</script>
</bsl-sandbox>
```

Код можно положить и в `<pre><code>…</code></pre>` внутри `<bsl-sandbox>`: без JavaScript читатель увидит обычный блок кода. Атрибуты: `theme="light|dark"`, `height="400"` (по умолчанию высота по содержимому), ввод — `<script type="text/bsl-input">`.

Хабр не разрешает сторонние скрипты и `<iframe>` в статьях, туда подходит только ссылка.

## Ограничения

Работает алгоритмическая часть языка: строки, числа, даты, коллекции, ТаблицаЗначений, исключения, а также язык запросов над таблицами значений и временными таблицами (`browser/Query/`, тесты: `python3 tests/run_query_tests.py <native.dll>`). Объектов конфигурации, информационной базы и форм нет, из БСП есть только заглушки функций, не обращающихся к базе. Остальное требует платформы 1С с информационной базой.
